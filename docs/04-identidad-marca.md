# Identidad de marca
Logotipo original sin modificar. Paleta: Marfil Cristal #FEFEFC (fondo), Burdeos Veralma #610139 (títulos), Ciruela Uva #8E1D56 (enlaces/precios), Dorado Vid #C79526 (botones con texto burdeos). Tipografías: Playfair Display Bold y Lora Regular.
Eslogan: «El alma verdadera de cada viñedo». «Veralma» = «vera» + «alma» es un concepto de marca propuesto, no un dato histórico.
